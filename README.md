# 수업실 — 국어 지문 수업 도구

기본 과목은 '국어'입니다. 과목(2022 개정 교육과정 과목 책장에서 선택)·앱 이름·인트로는 **설정 → 과목·이름**에서 바꿀 수 있습니다.

교재 PDF를 넣으면 지문 세트별로 챕터가 나뉘고, 배움열기 → 배움 → 배움공유 → 배움마무리 흐름으로 수업을 이 안에서 다 진행할 수 있습니다.

## 설치 (약 15분, 모두 무료)

### 1. 사이트 올리기 — GitHub Pages
1. github.com 가입 → **New repository** → 이름 예: `hwajak` → Public → Create
2. **Add file → Upload files** 로 이 폴더의 파일을 모두 끌어다 놓고 Commit
   (폴더 구조 `css/`, `js/` 그대로 올라가야 합니다)
3. **Settings → Pages** → Branch: `main`, 폴더 `/ (root)` → Save
4. 1~2분 뒤 `https://아이디.github.io/hwajak/` 로 접속

### 2. 학생 응답 서버 — Firebase
1. console.firebase.google.com → **프로젝트 추가** (Google 애널리틱스는 꺼도 됨)
2. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → 프로덕션 모드
3. **빌드 → Authentication → 시작하기 → Google** 사용 설정
4. **Authentication → 설정 → 승인된 도메인 → 도메인 추가** : `아이디.github.io`
5. **프로젝트 설정(톱니) → 내 앱 → 웹 `</>`** 앱 등록 → 나오는 `firebaseConfig` 값 복사
6. GitHub 저장소의 `config.js` 를 열어(연필 아이콘) 빈칸에 값 붙여넣기 → Commit
   - 또는 앱의 **설정 → 학생 응답 서버** 탭에 붙여넣어도 됩니다.
7. 앱에서 **교사 로그인**(Google) → **설정 → 학생 응답 서버** 탭의 **보안 규칙**을 복사 →
   Firestore → **규칙(Rules)** 탭에 붙여넣고 **게시**
   - 규칙의 이메일 목록에 함께 쓸 동료 선생님 계정을 추가하세요.

### 3. AI 키 (선택)
**설정 → AI** 에 Google Gemini(aistudio.google.com) 또는 Claude(console.anthropic.com) API 키를 넣으면
킬러 O/X, 구조화, PDF 지문 나누기, 띄어쓰기 정리, 세특 초안이 켜집니다.
키는 그 브라우저에만 저장됩니다.

## 동료 교사와 함께 쓰기
- 같은 사이트 주소를 쓰고, Firestore 규칙의 이메일 목록에 동료 계정을 넣으면 됩니다.
- 각자 로그인하면 지문·필기·칠판·출결·메모는 **자기 계정에 따로** 저장되고 다른 컴퓨터에서도 이어집니다.
- 지문 자료는 **설정 → 백업**, 성취기준은 **설정 → 성취기준 → 내보내기** 파일로 동료와 주고받으세요.

## 데이터와 개인정보
- 학생 응답(번호·이름·응답)은 선생님 소유의 Firebase에만 저장되며, 열람은 규칙에 등록한 교사 계정만 가능합니다.
- 학생은 로그인 없이 "제출"만 할 수 있습니다.
- 학기 말에는 학생부용 엑셀을 받아 두고 Firestore 데이터를 지우는 것을 권장합니다.

## 알아 두면 좋은 점
- 🔒 관찰 메모·성적 화면, 학생부용 엑셀, 전체 백업은 비밀번호(처음 값 6957)를 눌러야 열립니다. 설정 → 백업에서 바꿀 수 있어요. 화면 잠금이므로 학생과 함께 쓰는 컴퓨터에서는 수업 후 브라우저를 닫아 주세요.
- 스캔한(그림) PDF도 가져올 수 있습니다. 쪽 범위를 고른 뒤 ✨ AI로 글자 읽기(정확, AI 키 필요) 또는 🔤 무료 글자 인식(느림), 🖼 원본 그림으로만 중에서 고르세요.
- PDF에서 글자를 읽어 지문을 나누므로, 2단 편집·줄바꿈 때문에 띄어쓰기가 어색할 수 있습니다.
  가져오기 화면의 "줄 끝에서 낱말이 잘리는 PDF" 옵션이나 **편집 → ✨ 띄어쓰기 정리(AI)**, **✨ AI로 다시 나누기**를 쓰세요.
- 그림·표·매체 자료는 **원본** 버튼으로 PDF 쪽 이미지를 보며 판서할 수 있습니다.
- 서버를 연결하기 전(로컬 모드)에도 모든 교사 기능을 쓸 수 있고, 같은 브라우저의 새 탭에서 학생 화면을 시험해 볼 수 있습니다.


### 최근 바뀐 점
- '지필평가' 용어를 모두 '정기시험'으로 바꿈. 정기시험 안내는 가정통신문(HWP·PDF)에서 우리 과목의 날짜·교시·시험 범위·문항 구성·준비물·시간표만 골라 보여 줌(D-day 포함).
- 수행평가 안내: 채점 기준을 누르면 수준별 점수 산정 방법(상·중·하 점수, 감점, 점수 계산)이 크게 나옴.
- 배움에서 읽기 설계도·근거·함정·선배의 시선을 뺌. 칠판·학습지는 '수업 도구'로 묶음.
- 한글(HWP) 읽기 보강: 파일 형식 자동 판별, 배포용·암호 문서는 미리보기 글자로 앞부분만 읽기, 실패하면 이유를 보여 줌.
- 칠판 글자(𝐓): 글씨체 14가지·색 11가지(+직접)·크기 6단계·굵게 선택, 쓴 글자를 누르면 다시 고치기.
- 📚 설정 → 성취기준: 과목마다 붙여 넣어 두고 칠판의 성취기준 칸 📚 에서 골라 넣기, 동료와 파일로 공유.
- 🤝 설정 → 수업 약속: 시작 영상 5초 약속 문구 고치기(미리보기 포함).
- 🪑 자리 배치: 🚫 빈자리 지정(앉지 않을 자리 표시, 무작위·번호순 배치에서 건너뜀, 끌어서 옮기기).
- 📡 config.js에 Firebase 값을 넣어 배포하면 [설정 → 학생 응답 서버] 메뉴와 '서버 연결하기' 버튼이 숨겨짐.
- 📋 정기시험 안내: [📘 우리 과목] 고르기(예: 독서와 작문) — 시험 시간표는 모두, 시험 범위·문항·준비물은 이 과목 것만. AI가 없거나 실패해도 글에서 자동으로 골라 카드로 보여 주고 [✏️ 내용 고치기]로 바로잡기.
- ✅ 출결: 날짜·교시(1~8교시)마다 따로 저장, 앞 교시 결석 가져오기, 현황·엑셀도 교시별.
- 🔒 비밀번호: 화면에 숫자판 없이 키보드로만 입력(점만 표시) — 프로젝터에 노출되지 않음.
- 📱 배움열기·배움공유·배움마무리에서 [응답지 미리보기]: 학생 휴대폰 화면 그대로 보기(실제 제출 안 됨).
- 👩‍🏫 설정 → 과목·이름 → 교사 이름: 왼쪽 위 동그라미(조금 더 큼)와 시작 영상 도장에 이름이 들어감.
- ⏰ 어느 화면에서나 위쪽 가운데에 시계. 설정 → ⏰ 시정표에 학교 시간표를 넣으면 괄호 안에 '(3교시 · 12분 남음)', '(쉬는 시간 · 4교시까지 6분)'이 나오고, 끝나기 5분 전엔 빨갛게 바뀜. 전체 화면·발표 화면에서도 보임. 출결 체크는 지금 교시로 열림.
- 🩺 설정 → 📘 설치 안내 → [🩺 연결 점검]: 로그인·보안 규칙·이메일 목록을 실제로 시험해 어디가 막혔는지 알려 줌. 오류 알림도 원인별로 구체적으로 바뀜. 활동을 열 때 로그인이 안 되어 있으면 로그인 창을 바로 띄움.
- 🔑 학생 확인: 학생은 QR로 처음 들어올 때 반·번호·이름(명렬표와 일치)을 넣고 자기 비밀번호 4자리를 직접 정함. 다음부터는 그 비밀번호로 들어오고, 학생 화면 👤에서 바꿀 수 있음. 정하거나 바꾼 비밀번호는 선생님 쪽에 저장되어 설정 → 학급·명렬표에서 🔒[👁 비밀번호 보기]·[⬇️ 비밀번호 명단]으로 확인. 잊은 학생은 알려 주거나 🔄로 초기화(전체 초기화는 🔒). 5번 틀리면 1분 대기. 서버 보안 규칙에서도 확인(학생 비밀번호는 선생님 계정만 읽음). ※ firestore.rules 새로 게시 필요.
- 🏆 그랑프리 상패: 배움열기·배움마무리 응답 카드와 배움공유 모둠 카드의 [🏆 그랑프리]로 수여(옮기기·공동 수상·취소). 금빛 상패 시상 화면(꽃가루·팡파르), 상패 PNG 저장, 관찰 메모로 바로 남기기. 받은 학생 휴대폰에 축하 화면과 [내 상패 저장]. 응답 벽 🏆 필터, 학생부 엑셀에 그랑프리 열. 크게 보기·모둠 발표 화면에서도 [🏆 그랑프리] 버튼이나 G 키로 바로 수여.

## 🚀 배포 (GitHub → Vercel · Firebase)
1. 이 폴더 전체를 GitHub 저장소에 올리고 Vercel에서 그 저장소를 가져오기(Framework: Other, 빌드 명령 없음).
2. Firebase 콘솔
   - Authentication → 로그인 방법 → **Google 사용 설정**
   - Authentication → 설정 → 승인된 도메인 → **Vercel 주소(예: ezclass.vercel.app) 추가**
   - Firestore Database 만들기 → 규칙 탭에 **firestore.rules** 내용 붙여 넣고 게시 (동료 교사 이메일은 목록에 추가)
